风扇曲线

EC 直读 · OEM 表可写占空
曲线要手动读一次才会出来：EC 直读约 3 秒，OEM 表更快。读完后这里会画成温度-占空图。

点一下才读：EC 一轮要读近百个寄存器，所以不放进 2 秒轮询里。 OEM 表走 GCUBridge，只改占空比，16 个点一次下发；不改升温/降温阈值。

温度控制

TCC 偏移与换挡间隔
TCC 偏移 °C 风扇换挡间隔 ms

TCC 偏移越大越保守（更早降频）；风扇换挡间隔只收 100~2000 ms、100 的整数倍。 两条都是「值先发、开关最后发」，关闭时也会再发一次开关 0。读数在「硬件」页。

风扇固件行为

EC 实测 · 只读
0.5 % / 3 tick占空比斜坡：改表或切档后是慢慢爬上去的，不会瞬间变。
30 % 地板非零占空最低会被夹到 30 %；只有 0 % 才是真停转。
约 180 秒温度掉到停转阈值以下后，要等这段退避才真正停。
双阈值滞回升温和降温各用一条阈值，避免在边界上来回抖。
